鼻翼缘下移手术（遮挡鼻孔）

鼻翼缘下移是怎样做手术的？

有些人天生覆盖鼻孔的软组织不足，从正面就能看到鼻孔。

  • 97%鼻孔内侧疤痕不明显的患者
  • 20–40分钟手术时间（单侧 · 双侧）
  • 1周鼻尖胶布保留时间

TYPE · ALAR LOWERING

露出鼻孔的原因大致有4种。

  • 朝天鼻
  • 鼻孔上缘偏高的情况（M形鼻孔）
  • 鼻孔下缘偏低的情况（V形鼻孔）
  • 鼻孔大的情况

通常同时存在上述原因中2种以上的情况很多。

DOCTOR'S NOTE

金相浩院长的话

这是鼻孔外露的人常来寻求的手术

有些人天生覆盖鼻孔的软组织不足，从正面就能看到鼻孔。鼻孔这样外露，不仅外观上不好看，从面相学上也被认为是聚不住财的面相，所以希望矫正的顾客很多。

有些人天生鼻尖的部分鼻翼软骨发育不足、鼻翼一侧的软组织不足，鼻孔看起来呈三角形。两侧一起看就像字母M的形状，所以我个人把它叫做M形鼻孔。

— 金相浩
查看原文（韩语）

선천적으로 콧구멍을 덮고 있는 연부조직이 부족하여 정면에서 콧구멍이 보이는 분들이 있습니다. 이렇게 콧구멍이 노출되면 미관상으로도 보기가 좋지 않고 관상학적으로도 재물이 모이지 않는 상 이라 하여 교정을 원하시는 고객분들이 많답니다.

선천적으로 코끝의 날개연골 일부의 발달이 저하되어 있고, 콧날개쪽 연부조직이 부족한 경우에 콧구멍이 삼각형모양으로 보이는 경우가 있습니다. 양측을 같이 보면 알파벳 M 자 모양으로 보이기 때문에 저는 개인적으로 M자 콧구멍이라고 부릅니다.

M形鼻孔的三种类型

M形鼻孔大致可以分为三种type。根据鼻孔向上翘起的尖端位置是在内侧、中间还是外侧，分为type 1、2、3。

M形鼻孔Type 1是鼻孔向上尖起的部分集中在内侧的情况。在三种type中，是鼻翼缘下移手术效果最好的Type。

M形鼻孔Type 2是鼻孔向上尖起的部分位于中央的情况。在三种type中，是鼻翼缘下移手术效果居中的Type。

M形鼻孔Type 3是鼻孔向上尖起的部分向外侧张开的情况。在三种type中，是鼻翼缘下移手术效果最差的Type。

M 자 콧구멍은 크게 세가지 type 으로 나눌 수 있습니다. 콧구멍이 올라간 끝부분의 위치가 안쪽이냐, 중간이냐, 바깥쪽이냐에 따라 type 1,2,3 으로 나누고 있습니다.

M자 콧구멍 Type 1 은 콧구멍이 위쪽으로 뾰족한 부분이 안쪽에 몰려있는 경우입니다. 세가지 type중에서 비공내리기 수술의 효과가 가장 좋은 Type 입니다.

M자 콧구멍 Type 2는 콧구멍이 위쪽으로 뾰족한 부분이 중앙부에 위치한 경우입니다. 세가지 type 중에서 비공내리기 수술의 효과가 중간인 Type 입니다.

M자 콧구멍 Type 3 은 콧구멍이 위쪽으로 뾰족한 부분이 바깥쪽으로 벌어져 있는 경우입니다. 세가지 type중에서 비공내리기 수술의 효과가 가장 떨어지는 Type 입니다.

并不是所有M形鼻孔都需要矫正

并不是变成M形鼻孔就在所有情况下都显得难看。根据鼻孔底部的形态，鼻孔可能会显得更明显，也有鼻孔适当外露、反而得到鼻尖看起来更小的优点的情况。

也就是说，并不是所有M形鼻孔都需要矫正。最重要的是本人的主观判断。

— 金相浩

M자 콧구멍이 되었다고 해서 모든 경우에 미워보이는 것은 아닙니다. 콧구멍의 바닥쪽 형태에 따라 콧구멍이 더 보일수도 있고, 적당히 콧구멍이 노출되면서 코끝이 작아보이는 장점을 얻는 경우도 있답니다.

즉, 모든 M자 콧구멍이 교정을 필요로 하는 것은 아닙니다. 가장 중요한 것은 본인의 주관적인 판단입니다.

17年的鼻翼缘下移

17年来主刀鼻翼缘下移手术，在主要采用的软骨-皮肤复合组织移植方式上，手术方法大的变化有3次。现在主刀的手术方法是第3代鼻翼缘下移方式，大部分患者对鼻翼缘下移手术的结果非常满意。

但是，美容手术中不可能存在100%满意，所以我不谈理论，而是针对实际接受手术的患者哪怕有一点抱怨或感到不便的地方，以及按目前标准鼻翼缘下移手术的局限性，把17年的经验整理出来向大家报告。

— 金相浩

17년간 비공내리기 수술을 집도하면서 주로 수술하는 연골-피부 복합조직이식 방식에서 크게 3번의 수술 방법 변화가 있었습니다. 지금 집도하는 수술법은 3세대 비공내리기 방식인데요, 대부분의 환자분들이 비공내리기 수술 결과에 매우 만족하십니다.

하지만, 미용수술에서 100% 만족이라는 것이 존재할 수 없기 때문에 이론적인 부분이 아닌 실제 수술 받은 환자분들이 조금이라도 컴플레인 하셨거나, 불편을 느끼셨던 부분에 대해서 그리고, 현재 기준 비공내리기 수술의 한계점에 대해 17년간의 경험을 정리해서 보고해드립니다.

METHOD

手术方法

  1. STEP 01

    睡一觉醒来，手术就已经结束了。

  2. STEP 02

    采用同时移植耳软骨和皮肤的复合组织移植方法进行手术，

  3. STEP 03

    用尽量避免这种方式的缺点——鼻尖变得臃肿——的第3代鼻翼缘下移手术方法，

  4. STEP 04

    只做单侧时，手术时间大约需要20分钟。

  5. STEP 05

    术后在鼻尖贴一周左右的肤色胶布。

这是从双侧耳朵取得软骨+皮肤组织、移植到鼻孔内侧的手术方法，在睡眠麻醉下进行，时间大约需要40分钟。

因为要把鼻尖皮肤往下放来遮挡鼻孔，鼻尖变大是必然的。特别是术后3个月内还叠加了手术肿胀，鼻尖看起来更加臃肿。

原本担心的人在消肿后大部分也都满意，但大约每2~3年会有一位希望为了减少鼻尖体积，把移植部位部分或全部取出。

RECOVERY

恢复

  1. 手术当天

    睡一觉醒来，手术就已经结束了。

    完全没有疼痛。

  2. 1周

    术后在鼻尖贴一周左右的肤色胶布。

    去掉胶布后可以洗脸和化妆，虽然还有些肿，但大部分人都能正常生活。

  3. 2周

    通常2周左右就可以基本不影响日常生活，但根据鼻子形态或体质，也有少数情况初期肿胀较重、持续较久。

  4. 2个月

    术后2个月内绝对禁止烟酒，除此之外没有需要特别注意的事项。

    在移植的皮肤完全成活之前，要好好涂药膏保持湿润环境，并按预约的治疗日期按时来院即可。

  5. 肿胀

    鼻尖肿胀会在6~12个月内持续消退。

手术在睡眠麻醉下进行，鼻子外部没有切口，只在鼻孔内侧切开，所以没有外露的疤痕。

FAQ

常见问题

鼻翼缘下移手术可以取出吗？

<< 鼻翼缘下移手术无论什么时期都可以取出 >> 只是手术初期的部分取出，除非非常特殊的情况，否则不推荐。因为部分取出后，剩下的移植物也可能坏死，最终不得不全部取出。

术后鼻孔内侧会看到疤痕吗？

97%的患者鼻孔内侧疤痕不明显。大约3%，尤其是“龙鼻”的情况，从下方看时皮肤移植部位可能看起来像疤痕。

“龙鼻”（Type 3）也能做鼻翼缘下移吗？

“龙鼻”形态的Type 3鼻孔，做鼻翼缘下移手术时鼻孔会遮挡得不好看。正面鼻孔外露不多的“龙鼻”，不推荐做鼻翼缘下移手术。

从耳朵取软骨和皮肤，耳朵形状会改变吗？

取耳软骨+皮肤后，耳朵会稍微变短、向后贴。到目前为止还没有听到过因耳朵形状变化而产生的抱怨。

术后会呼吸不畅吗？

因为是在鼻孔入口处做手术，理论上存在对呼吸产生些许影响的可能性。单独做鼻翼缘下移手术后出现呼吸不畅而成为问题的情况，目前还没有见过。
