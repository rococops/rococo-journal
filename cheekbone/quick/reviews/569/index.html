변형 15분광대축소술 후기!!

어릴 때는 광대가 안나왔는데 크면서 광대가 계속 커지는 느낌이랄까 항상 돌출된 광대뼈가 콤플렉스였고, 사진찍을 때도 광대뼈가 제일 신경쓰였고 광대수술이 뼈수술이어서 늘 고민했다가 1년 정도 김상호 원장님 블로그랑 로코코 홈페이지에 후기들을 보면서 고

감사해요님 후기· 15분 광대축소술· 로코코성형외과

어릴 때는 광대가 안나왔는데 크면서 광대가 계속 커지는 느낌이랄까

항상 돌출된 광대뼈가 콤플렉스였고, 사진찍을 때도 광대뼈가 제일 신경쓰였고 광대수술이 뼈수술이어서 늘 고민했다가 1년 정도 김상호 원장님 블로그랑 로코코 홈페이지에 후기들을 보면서 고민했어요!

상담받을 때 저는 B타입이라 하셔서 앗 그럼 효과가 있겠구나 기대했는데 관자가 꺼져있고 볼살도 좀 들어가 있어서 잔붓기가 다 빠지면 약간 나와보일 수 있다고 설명해주셨고,

제가 예상했던것처럼 측면에서 봤을 때 45도 광대가 쑥 없어지지는 않을거라 하셔서 수술 전에 효과가 없으면 어쩌나 하는 걱정이 많이 들었어요 ㅠㅠ큰맘먹고 하는 수술이니..

그래서인지 계속 원장님께 안전한 범위 내에서 최대한 넣어달라고 말씀드렸던 것 같아요!

그래도 늘 안전을 최우선시하시고 예쁘게 해주신 원장님을 믿기로 하고 수술대에 누웠지요^^

내시경도 받아본적이 없어서 수면마취는 어떨까 걱정이 많이들었어요.

두 번 마취를 하는데 첫번째는 광대부위에 마취하기 위해 잠깐 하는 마취고, 깼다가 다시 잠에 드는데

첫번째 마취는 롤러코스터?를 타는 느낌이었어요.

후기 중에 롤러코스터 타는 느낌이라는 분이 많으셔서 '아..나는 롤러코스터 무서워서 못타는데..무서워서 움직이면 어떡하지?'하는 걱정도 있었는데 무서운 롤러코스터가 아니라 그냥 뭔가 빠르게 움직이고 신비로운..?느낌이랄까 그랬어요~

롤러코스터를 타는데 옆에서 '점심 뭐먹지?'하는 대화도 들었던 것 같아요! 꿈인가...아님 간호사님인가 모르겠어요 ㅎㅎ

그뒤로부터는 정신이 없었던 것 같아요

마취 때 뭘 보지도 않았고, 그냥 깊이 잠이 든 느낌이었달까..

제가 마취 때 이상한 소리는 안했을지 걱정이었어요^^;;

정신을 차려보니 수술이 끝나있고 간호사님께서 회복실로 가자고 하시는데 걸으셔야 한다고 그러셨어요. 그 때 뭔가 정신이 완전히 돌아오지 않아서 다리에 힘이 풀리고 그랬는데 저 부축해주시느라 고생하신 간호사님께 감사해요ㅠㅠ

회복실에서 조금 지나자 정신이 돌아오면서 잠이 깼는데 저는 심하게 토할 것 같진 않고 살짝 멀미난다는 느낌이었어요

가끔 심하게 흔들리는 차 탈 때 나는 멀미 느낌 정도..?

근데 한시간 정도 지나면 이것도 금방 괜찮아져요~

정신이 돌아오자마자 결과가 너무 궁금해서 손으로 살짝 만져봤는데 뭔가 라인이 들어간 것 같은 느낌!

원장님을 뵈었는데 원장님께서 수술은 잘 되었다고 해주셔서 안심이었어요~ㅎㅎ

그래도 얼마나 들어간건지 진짜 너무 궁금해서 땡김이 풀고 거울을 많이 봤던 것 같아요!

거울 볼 때 빼고는 열심히 땡김이도 했답니다!

수술 후에 사실 가벼운 운동도 조금씩하고 그랬는데 상처도 잘 아문것같고 수술 후 불편함은 없었어요

가끔씩 뼈에서 소리가 나기도 했지만 시간이 지나면서 괜찮아졌구요!

옆광대의 경우 전보다 들어간것같긴한데 변형 15분이었는데 45도 광대가 들어간건지는..잘모르겠어요

두달째인데 눈으로 보이는 붓기는 없는것같고

잘먹고 잘 쉬어서인지 수술했다는게 아주 오래전일같아요!

2달이면 뼈가 다 붙는다하셨던 말대로 불편함없이 잘지내고있습니다^^

안전하게 해주셔서 감사해요!!뼈수술인데 이렇게 안전하게 할 수 있었단게 참 감사합니다~~~

그런데 차후 관리를 어떻게 해야하는지 궁금합니다

잘 때 옆으로 자고 그랬는데 그게 영향을 끼쳤는지...

45도광대가 많이 안들어간건지 걱정도 되고..궁금해요

다음달에 경과보러 찾아뵙겠습니다~~~
