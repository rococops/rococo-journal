로코코에서 수술 결정한 이유들

해외거주자님 후기· 늑연골 명품코성형· 로코코성형외과

저는 해외 거주자라 직접 병원 여러곳 이곳저곳 둘러보며 직접 얼굴 내밀고 상담 받지 못하고 인터넷으로만 여러 병원 둘러봤어요. 인터넷만으로 봐도 로코코가 좋아서 저는 한국 도착해서 다른 병원은 아예 상담도 안받고 바로 로코코로 와서 상담 및 수술 바로 진행했어요.

제가 로코코로 결정한 이유는

1. 홈페이지에 의사 선생님이 직접 작성하신 글이 여럿 올라와있어요. 이렇게 후기 올리면 답 올려주시는 것 부터 이 수술은 어떤거다 등등 친근하게 직접 글을 써주신것에 감동했어요. 다른 홈피는 그냥 광고를 보는 것 같다면 로코코는 직접 의사쌤 얘기를 듣는 느낌이랄까요.

2. 불필요한 걸 없앴다는 것도 엄청난 장점이였지요. 광대 수술 후 얼굴에 철심이 여럿 박혀있다 생각하면 솔직히 좀 부담스럽거든요. 치과만 가도 표시날 것 같고.. 의사쌤이 기술이 남다르다보니 비고정으로도 수술이 된다길래 그럼 당연 비고정으로 가야죠. 불필요한 엑스레이 안찍는것도 보너스.

3. 로코코 직원분들 카톡상담 친절하게 잘 해주시는 점에도 반했어요! 어찌보면 뜬금없는 질문도 많이 했는데 조목조목 얼마나 잘 설명을 해주시는지.. 다시한번 감사해요! 어제 수술받느라 직접 직원분들 만났는데 네.. 역시나 친절하시더라구요. 그리고 다들 웃는 모습들이 얼마나 보기 좋은지 아주 그냥 제가 남자였으면 심장이 콩닥콩닥 했을 겁니다.

4. 수술 시간이 짧아 붓기와 멍이 적고 회복기간이 다른 병원보다 짧더라구요. 후기를 읽어보면 왜 다들 안아프다 하시는지.. 뼈를 움직이는 큰 수술인데 안 아플수가 있나 고개 갸우뚱 하면서도 로코코가 끌리는 건 어쩔수가 없더라구요. 수술도 전신 마취가 아닌 수면 마취라는 것!

5. 결과가 어떨것이다 솔직하게 얘기해주신다는 점. 한명이라도 수술 더 하기 위해 무조건 효과 있어요! 과대포장 하지 않고 상담 후 그럼 수술 안할게요 얘기 들을 지언정 솔직하게 결과를 얘기해주시는 점이 좋았어요! 저는 B랑 C 중간타입이라고 별로 효과 없을거라 하셨는데 그래도 했어요ㅎㅎ 워낙 심한 비대칭이라 광대라도 좀 비슷하게 들어가면 나중에 지방이식 등으로 비대칭 조금이나마 줄일 수 있지 않을까 해서요.

어제 변형광대 + 아큐스 수술 잘 받았구요, 수술 후기는 나중에 경과 보면서 다시 올릴게요.
