TYPE · ALAR LOWERING

鼻の穴が見える原因は、大きく4つあります。

  • 豚鼻（上向きの鼻）
  • 鼻の穴の上側が上がっている場合（M字の鼻孔）
  • 鼻の穴の下側が下がっている場合（V字の鼻孔）
  • 鼻の穴が大きい場合

通常、上記の原因のうち2つ以上が同時にあることが多いです。

DOCTOR'S NOTE

キム・サンホ院長の話

鼻の穴が見える方が多く求める手術です

生まれつき鼻の穴を覆っている軟部組織が不足していて、正面から鼻の穴が見える方がいます。このように鼻の穴が露出すると、見た目にもよくなく、人相学的にも財が集まらない相だとされ、矯正を希望されるお客様が多いのです。

生まれつき鼻先の鼻翼軟骨の一部の発達が弱く、小鼻側の軟部組織が不足している場合に、鼻の穴が三角形に見えることがあります。両側を一緒に見るとアルファベットのM字の形に見えるため、私は個人的に「M字の鼻孔」と呼んでいます。

— キム・サンホ

선천적으로 콧구멍을 덮고 있는 연부조직이 부족하여 정면에서 콧구멍이 보이는 분들이 있습니다. 이렇게 콧구멍이 노출되면 미관상으로도 보기가 좋지 않고 관상학적으로도 재물이 모이지 않는 상 이라 하여 교정을 원하시는 고객분들이 많답니다.

선천적으로 코끝의 날개연골 일부의 발달이 저하되어 있고, 콧날개쪽 연부조직이 부족한 경우에 콧구멍이 삼각형모양으로 보이는 경우가 있습니다. 양측을 같이 보면 알파벳 M 자 모양으로 보이기 때문에 저는 개인적으로 M자 콧구멍이라고 부릅니다.

M字の鼻孔の3つのタイプ

M字の鼻孔は大きく3つのtypeに分けることができます。鼻の穴が上がった頂点の位置が内側か、中間か、外側かによって、type 1・2・3に分けています。

M字の鼻孔Type 1は、鼻の穴の上に尖った部分が内側に寄っている場合です。3つのtypeのうち、鼻孔縁下降術の効果が最も良いTypeです。

M字の鼻孔Type 2は、鼻の穴の上に尖った部分が中央部にある場合です。3つのtypeのうち、鼻孔縁下降術の効果が中程度のTypeです。

M字の鼻孔Type 3は、鼻の穴の上に尖った部分が外側に開いている場合です。3つのtypeのうち、鼻孔縁下降術の効果が最も低いTypeです。

— キム・サンホ
原文（韓国語）を見る

M 자 콧구멍은 크게 세가지 type 으로 나눌 수 있습니다. 콧구멍이 올라간 끝부분의 위치가 안쪽이냐, 중간이냐, 바깥쪽이냐에 따라 type 1,2,3 으로 나누고 있습니다.

M자 콧구멍 Type 1 은 콧구멍이 위쪽으로 뾰족한 부분이 안쪽에 몰려있는 경우입니다. 세가지 type중에서 비공내리기 수술의 효과가 가장 좋은 Type 입니다.

M자 콧구멍 Type 2는 콧구멍이 위쪽으로 뾰족한 부분이 중앙부에 위치한 경우입니다. 세가지 type 중에서 비공내리기 수술의 효과가 중간인 Type 입니다.

M자 콧구멍 Type 3 은 콧구멍이 위쪽으로 뾰족한 부분이 바깥쪽으로 벌어져 있는 경우입니다. 세가지 type중에서 비공내리기 수술의 효과가 가장 떨어지는 Type 입니다.

キム院長のコラムより（韓国語）→

すべてのM字の鼻孔に矯正が必要なわけではありません

M字の鼻孔だからといって、すべての場合に見た目が悪くなるわけではありません。鼻の穴の底側の形によっては鼻の穴がより見えることもあり、適度に鼻の穴が見えることで鼻先が小さく見えるという長所が得られる場合もあるのです。

つまり、すべてのM字の鼻孔が矯正を必要とするわけではありません。最も重要なのはご本人の主観的な判断です。

— キム・サンホ
原文（韓国語）を見る

M자 콧구멍이 되었다고 해서 모든 경우에 미워보이는 것은 아닙니다. 콧구멍의 바닥쪽 형태에 따라 콧구멍이 더 보일수도 있고, 적당히 콧구멍이 노출되면서 코끝이 작아보이는 장점을 얻는 경우도 있답니다.

즉, 모든 M자 콧구멍이 교정을 필요로 하는 것은 아닙니다. 가장 중요한 것은 본인의 주관적인 판단입니다.

17年間の鼻孔縁下降術

17年間鼻孔縁下降術を執刀する中で、主に行っている軟骨・皮膚の複合組織移植の方式において、大きく3回の手術方法の変化がありました。現在執刀している手術法は第3世代の鼻孔縁下降術の方式で、ほとんどの患者さんが鼻孔縁下降術の結果にとても満足されています。

しかし、美容手術において100%の満足というものは存在しえないため、理論的な部分ではなく、実際に手術を受けた患者さんが少しでも不満をおっしゃったり不便を感じられたりした部分について、そして現時点での鼻孔縁下降術の限界について、17年間の経験をまとめてご報告します。

— キム・サンホ
原文（韓国語）を見る

17년간 비공내리기 수술을 집도하면서 주로 수술하는 연골-피부 복합조직이식 방식에서 크게 3번의 수술 방법 변화가 있었습니다. 지금 집도하는 수술법은 3세대 비공내리기 방식인데요, 대부분의 환자분들이 비공내리기 수술 결과에 매우 만족하십니다.

하지만, 미용수술에서 100% 만족이라는 것이 존재할 수 없기 때문에 이론적인 부분이 아닌 실제 수술 받은 환자분들이 조금이라도 컴플레인 하셨거나, 불편을 느끼셨던 부분에 대해서 그리고, 현재 기준 비공내리기 수술의 한계점에 대해 17년간의 경험을 정리해서 보고해드립니다.

METHOD

手術方法

  1. STEP 01

    眠って目が覚めると、手術は終わっています。

  2. STEP 02

    耳の軟骨と皮膚を同時に移植する複合組織移植の方法で手術しますが、

  3. STEP 03

    この方式の短所である鼻先がぼてっと大きくなることを最大限防ぐ第3世代の鼻孔縁下降術で、

  4. STEP 04

    手術時間は片側だけの場合、おおよそ20分ほどかかります。

  5. STEP 05

    手術後、鼻先に肌色のテープを1週間ほど貼ります。

キム院長のコラムより（韓国語）→

両耳から軟骨＋皮膚の組織を採取して鼻の穴の内側に移植する手術法で、静脈麻酔（睡眠麻酔）で手術し、時間はおおよそ40分かかります。

キム院長のコラムより（韓国語）→

鼻先の皮膚を下ろして鼻の穴を隠さなければならないため、鼻先が大きくなるのは避けられません。特に手術後3か月までは、手術の腫れも加わって鼻先がよりぼてっと見えます。

心配されていた方も腫れが引いた後はほとんど満足されますが、おおよそ2〜3年に1人ほどは、鼻先のボリュームを減らすために移植した部分の一部または全部の除去を希望されます。

キム院長のコラムより（韓国語）→
RECOVERY

回復

  1. 手術当日

    眠って目が覚めると、手術は終わっています。

    痛みはまったくありません。

  2. 1週間

    手術後、鼻先に肌色のテープを1週間ほど貼ります。

    テープを外した後は洗顔・メイクが可能で、少し腫れた状態ですが、ほとんどの方が日常生活を送られます。

  3. 2週間

    通常2週間ほどで日常生活に大きな支障なく過ごせますが、鼻の形や体質によって、初期の腫れが強く長引く場合もまれにあります。

  4. 2か月

    手術後2か月間はお酒・たばこは絶対に禁止で、それ以外に特に気をつけることはありません。

    移植した皮膚が完全に生着するまでは軟膏をしっかり塗って湿潤な環境を保つ必要があり、治療の予約日にきちんと来院していただければ大丈夫です。

  5. 腫れ

    鼻先の腫れは6〜12か月まで少しずつ引いていきます。

FAQ

よくある質問

鼻孔縁下降術は除去できますか？

<< 鼻孔縁下降術は時期に関係なく除去が可能です >> ただし、手術初期の部分除去は、よほど特別な場合でなければおすすめしません。部分除去をしたところ、残っている移植片も壊死して、結局全部除去しなければならなくなることもあるからです。

キム院長のコラムより（韓国語）→
手術後、鼻の穴の内側に傷跡が見えますか？

97%の患者さんでは、鼻の穴の内側の傷跡は目立ちにくいです。おおよそ3%ほど、特に龍鼻（ヨンコ：Type 3の鼻孔）の場合に、下から見ると皮膚を移植した部分が傷跡のように見えることがあります。

キム院長のコラムより（韓国語）→
龍鼻（ヨンコ・Type 3）でも鼻孔縁下降術はできますか？

龍鼻（ヨンコ）の形のType 3の鼻孔では、鼻孔縁下降術の際に鼻の穴がきれいに隠れません。正面からの鼻の穴の露出が多くない龍鼻（ヨンコ）には、鼻孔縁下降術はおすすめしません。

キム院長のコラムより（韓国語）→
耳から軟骨と皮膚を採取すると、耳の形が変わりますか？

耳の軟骨＋皮膚の採取後、耳が少し短くなり、後ろ側に寄ります。これまで耳の形の変化について不満を言われたことはありません。

キム院長のコラムより（韓国語）→
手術後、呼吸がしにくくなりますか？

鼻の穴の入り口側で手術をするため、呼吸に少しでも影響を及ぼす理論的な可能性はあります。鼻孔縁下降術の単独手術後に呼吸のしにくさが生じて問題になったケースは、まだ見たことがありません。
